# CAR DAI placeholder README.

This repo contains a playable Godot 4 foundation for the CAR DAI driving game prototype.

Quick start:
1. Open the project in Godot 4.x.
2. Press F5 to run the project.
3. From the main menu, select PLAY to test the open-world driving prototype.

Included systems:
- Main menu UI
- World test map
- Drivable 3D car prototype
- HUD and mobile touch controls
- Basic traffic cars
- Basic garage
- Scene structure ready for expansion

For the full production version, the systems can be expanded into modular vehicles, missions, weather, save states, and more.
